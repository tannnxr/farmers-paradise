# FarmersParadise

**FarmersParadise** is a Fabric mod for Minecraft that expands farming with new crops, recipes, plants, and mobs designed around a richer agricultural experience.

## Features

- New farmable crops
- New farming-related recipes
- Additional plants for world-building and decoration
- Farming-themed mobs
- More variety for survival farming progression
